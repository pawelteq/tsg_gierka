# Zimowy szlak

Otwórz `WinterSummit.unity` i naciśnij Play. Skacz po 17 ośnieżonych półkach, zbierz 8 światełek i dotrzyj do latarni na szczycie. Po upadku podróż zaczyna się od nowa.

- A / D lub strzałki: ruch
- Spacja, W lub strzałka w górę: skok
- R: rozpocznij od nowa
- M: włącz / wyłącz dźwięk

Scena zawiera edytowalne obiekty: góry, zorzę, las, platformy, latarnie i postać w czerwonej kurtce. Folder Art zawiera własne siatki i materiały; Audio zawiera sześć oryginalnych, syntetyzowanych plików WAV: wiatr, kroki, skok, lądowanie, zbieranie światełka i finał. Nie wymaga pobierania zewnętrznych zasobów.

Ruch: `Assets/Scripts/PlayerMovement.cs`. Prezentacja, dźwięki i postęp: `Assets/Scripts/WinterAdventure.cs`. Poprzednia scena `Assets/KUBA/scena1.unity` pozostaje dostępna.
